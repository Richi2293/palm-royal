# Miramar interiors and window renovation

Open `coastal-city-interiors.blend`. The previous city versions remain separate.

## Changes

The Palm Royal front and side facades and the cafe upper front now have true openings rather than glass panels in front of solid walls. Glazing has low-roughness transmission with an architectural glass IOR. Framed openings include sills, mullions, hardware, pleated curtains, floors, and interior depth. Hotel front rooms include basic bed and lamp furniture; some curtains remain partially closed to vary the facade.

Café Miramar has customer circulation from the open street entrance, a rear service bar, marble surfaces, wood flooring, olive upholstered booths, tables, bar stools, an espresso machine, pastry vitrine, scanned pastries, bottles, a menu board, cups, plants, and warm pendant lights.

## Views

- Camera 07: exterior cafe inspection.
- Camera 08: inside Café Miramar.
- Camera 09: real glazing and room depth.

The default render camera is 07. Select another camera and use Ctrl+Numpad 0 or View > Cameras > Set Active Object as Camera. For free exploration, leave camera view and use F3 > Walk Navigation. W/A/S/D moves, E/Q moves vertically with gravity off, the mouse looks around, and the wheel adjusts speed. Left-click keeps the new position; Esc restores the starting position.

Material Preview can simplify transmission. Use Rendered shading or F12 for the final glass and lighting appearance. The finished preview PNGs are provided separately. This is an editable architectural scene, not a collision-tested game level.

Run `upgrade_windows_cafe.py` with Blender in background mode to rebuild from `coastal-city-detailed.blend`. The file packs its textures. Credits and original asset sources are listed in [asset-credits.md](asset-credits.md).
